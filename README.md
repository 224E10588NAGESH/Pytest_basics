# Pytest_basics

## Hands-on Experience

I gained hands-on experience using **Pytest** to write and execute automated tests for Python applications. Through this project, I practiced:

- Writing clear test cases using Python functions
- Using `assert` statements to validate expected outcomes
- Running tests with the `pytest` command
- Organizing test files and test functions using Pytest conventions
- Testing functions with different input values
- Understanding test discovery and Pytest output
- Identifying failures and debugging test results
- Building repeatable automated checks for application behavior

This practice strengthened my understanding of Python testing principles and helped me develop a foundation for writing reliable, maintainable test suites.
